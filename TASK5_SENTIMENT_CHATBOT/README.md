# Sentiment Analysis Chatbot

## Objective
This project integrates sentiment analysis into a chatbot to detect customer emotions and respond appropriately.

## Features
- Detects Positive, Negative, and Neutral sentiments.
- Provides emotion-based chatbot responses.
- Simple Flask web interface.

## Technologies Used
- Python
- Flask
- TextBlob
- HTML
- CSS

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run:
   python app.py

3. Open:
   http://127.0.0.1:5000
